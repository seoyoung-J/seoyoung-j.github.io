## Getting Started Locally

Clone the repository.

```bash
git clone https://github.com/seoyoung-J/seoyoung-j.github.io.git
cd seoyoung-j.github.io
```

Install dependencies.

```bash
pnpm install
```

Start the development server.

```bash
pnpm dev
```

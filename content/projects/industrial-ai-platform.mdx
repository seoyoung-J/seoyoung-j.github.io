## 프로젝트 개요

제조 현장의 외관 검사는 작업자의 육안 판단에 따라 검사 결과에 편차가 발생하거나 결함을 놓칠 수 있으며, 결함 이미지와 라벨을 충분히 확보하기 어려워 모든 결함 유형을 사전에 학습하는 데 한계가 있습니다. 이에 이미지 기반 검사 판정과 이상 위치 확인을 지원하고, 문서 기반 설비 점검 가이드로 후속 대응을 돕는 플랫폼을 구현했습니다.

**부품 형상·구조의 이상을 검사하는 Object 유형과 표면·패턴 변화를 검사하는 Texture 유형을 구분**하고, **빠른 1차 판정을 위한 속도형과 정밀 분석을 위한 성능형 모델 프로파일로 구성**했습니다. 각 프로파일은 정상 이미지 특징을 기준으로 정상·불량·재검사를 판정하고, heatmap으로 이상 위치를 제공합니다.

PatchCore는 정상 이미지의 특징을 Memory Bank에 저장해 이상 여부를 판단합니다. **신규 품목 등록 시 선택한 모델 프로파일의 Backbone과 feature layer를 유지하고, 해당 품목의 정상 이미지로 품목별 Memory Bank를 생성하도록 구성**했습니다. 분석 결과와 관련 설비 문서를 함께 제공해 작업자의 후속 점검과 조치를 지원합니다.

## 담당 역할

**속도형 이상 탐지 모델 비교 및 선정**

- WideResNet50 기반 PatchCore·PaDiM, EfficientAD를 판정 성능, 이상 위치 성능, 처리 속도와 GPU 메모리 기준으로 비교
- Object·Texture 유형과 feature layer별 결과를 검증해 WideResNet50 + PatchCore layer2를 속도형 모델로 선정

**PatchCore 파라미터 및 Memory Bank 최적화**

- 입력 해상도, 정상 이미지 수와 Memory Bank 크기에 따른 판정·이상 위치 성능 및 처리 속도 비교
- Object와 Texture 특성에 맞는 입력 해상도와 Memory Bank 크기를 선정해 저장 patch feature 수를 축소

**Teacher–Student 기반 경량화 실험**

- ResNet18, EfficientNet-B0, MobileNetV3-small의 판정 성능, 이상 위치 성능, 추론 속도와 GPU 메모리를 비교
- MobileNetV3-small을 경량 후보로 선정하고 Heatmap Loss, Score Loss와 Mask Loss 구성에 따른 성능 비교

#### **결과**

WideResNet50 + PatchCore layer2를 선정해 **Peak GPU Memory를 Object 63.2%·Texture 63.8% 절감**하고, Memory Bank 최적화로 **저장 patch feature를 Object 50%·Texture 75% 축소**했습니다.

#### **추가 실험 및 판단**

- PatchCore layer3 — GPU 메모리는 낮았지만 판정·이상 위치 성능이 하락해 제외
- PatchCore layer2+layer3 — 제한적인 성능 차이에 비해 GPU 메모리 증가 폭이 커 제외
- PaDiM·EfficientAD — PatchCore layer2보다 판정 또는 이상 위치 성능이 낮아 제외

## 회고 및 배운점

이상 탐지 모델을 서비스 목적에 맞게 선정하려면 Image AUROC뿐 아니라 판정·위치 성능, 처리 속도와 GPU 메모리를 함께 비교해야 한다는 점을 배웠습니다. PatchCore에서는 정상 분포를 유지하는 범위에서 Memory Bank 크기와 검색 비용을 함께 조정하는 것이 중요했습니다.

Teacher–Student 실험에서는 경량화 과정에서도 위치 성능을 별도로 검증하고, Loss·feature 구성에 따른 성능과 자원 효율의 trade-off를 함께 판단해야 한다는 점을 확인했습니다.

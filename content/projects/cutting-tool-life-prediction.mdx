## 프로젝트 개요

제조 공정에서는 절삭 공구의 마모와 파손 시점을 사전에 파악하지 못할 경우 생산 중단, 가공 품질 저하와 유지보수 비용 증가로 이어질 수 있습니다. 이에 CNC 밀링 공정에서 수집된 진동·전류 센서 요약 피처와 공정 메타데이터를 활용해 절삭 공구의 잔여수명(RUL)을 예측하는 회귀 모델을 개발했습니다.

14개 절삭공구의 전체 수명 주기와 968개 밀링 사이클 데이터를 활용했으며, 공구 식별자를 기준으로 GroupKFold를 적용해 동일 공구의 데이터가 학습과 검증에 함께 포함되는 데이터 누수 가능성을 낮췄습니다. 타깃 정의, 회귀 모델, 하이퍼파라미터 튜닝과 피처 구성을 비교해 최종 Top-30 ExtraTreesRegressor를 선정했습니다.

## 트러블슈팅

### **01. 타깃 정의에 따른 회귀 성능 저하 개선**

#### **문제 상황**

공구 고장까지 남은 실제 cycle 수인 CycleToFailure를 그대로 타깃으로 사용했을 때 GroupKFold 기준 R²가 음수로 나타나 공구별 잔여수명 패턴을 안정적으로 학습하지 못했습니다. 공구마다 전체 수명 길이가 달라 절대 cycle 수를 그대로 비교하는 방식이 모델 학습에 적합한지 다시 검토할 필요가 있었습니다.

#### **해결 과정**

##### **1. 타깃 구성 비교**

- CycleToFailure와 이를 0~1 범위로 정규화한 CycleToFailureNormalized 비교
- RandomForestRegressor를 기준 모델로 두고 모든 조합을 동일한 GroupKFold 조건에서 평가

##### **2. 공구 사용 이력 변수 검증**

- 공구의 누적 가공 횟수를 나타내는 NumberOfCycle 포함 여부 비교
- **CycleToFailureNormalized와 NumberOfCycle을 함께 사용한 구성을 이후 모델 실험의 입력 구성으로 선정**

#### **결과**

CycleToFailure를 사용한 조합에서는 R²가 모두 음수였지만, CycleToFailureNormalized와 NumberOfCycle을 적용한 기준 모델은 평균 MAE 0.12, RMSE 0.16, R² 0.65를 기록했습니다. 이후 해당 타깃 구성을 고정하고 7개 회귀 모델 비교와 하이퍼파라미터 튜닝을 진행했습니다.

### **02. 피처 최적화를 통한 ExtraTrees 성능 개선**

#### **문제 상황**

7개 회귀 모델 비교와 상위 모델 튜닝 후 ExtraTreesRegressor를 선정했지만, 전체 피처를 사용한 13-fold GroupKFold 평가에서 평균 R²는 0.79였습니다. 또한 중요 피처 사이에 높은 상관관계가 확인되어, 예측에 필요한 정보를 유지하면서 피처 구성을 최적화할 필요가 있었습니다.

#### **해결 과정**

##### **1. Top-N 피처 비교**

- Feature Importance 기준 Top-10, Top-20, Top-30과 전체 피처 구성 비교
- 동일한 ExtraTrees 조건에서 평가해 평균 R²가 가장 높았던 **Top-30 선정**

##### **2. 다중공선성 축소 검증**

- 상관계수 0.9 이상인 피처를 그룹화해 30개를 16개로 축소
- 16개 Reduced 구성과 Top-30의 성능을 동일 조건에서 비교
- Reduced 구성의 성능이 낮아 **Top-30 유지**

##### **3. 추가 하이퍼파라미터 튜닝**

- Top-30을 고정한 상태에서 GridSearchCV와 Optuna 추가 비교
- 두 추가 튜닝 결과 모두 기존 Top-30 ExtraTrees보다 성능이 높아지지 않아 미채택

#### **결과**

Top-30 피처를 적용하면서 평균 R²가 **0.79 → 0.82**, MAE가 **0.10 → 0.09**로 개선됐습니다.

최종 모델은 13-fold GroupKFold에서 평균 R² 0.82, MAE 0.09, RMSE 0.12를 기록한 **Top-30 ExtraTreesRegressor로 선정**했습니다.

| 피처 구성 | R² | MAE | RMSE | 판단 |
| :---: | :---: | :---: | :---: | :---: |
| 전체 피처 | 0.79 | 0.10 | 0.12 | 비교 기준 |
| **Top-30** | **0.82** | **0.09** | **0.12** | **최종 선정** |
| 상관관계 기반 16개 | 0.81 | 0.10 | 0.12 | 미채택 |

#### **추가 실험 및 판단**

- 16개 피처 축소 — 입력 변수는 줄었지만 세 평가 지표 모두 Top-30보다 낮아 미채택
- GridSearchCV — 추가 탐색 후에도 기존 Top-30 설정보다 R²가 낮아 미채택
- Optuna — GridSearchCV와 기존 설정 모두보다 성능이 낮아 미채택

## 회고 및 배운점

정형 데이터 회귀에서는 모델 종류뿐 아니라 타깃 정의와 검증 데이터 분리 기준이 성능 해석에 큰 영향을 준다는 점을 확인했습니다. 동일 공구의 여러 cycle을 무작위로 나누는 대신 공구 단위 GroupKFold를 적용하면서 학습에 포함되지 않은 공구에 대한 일반화 성능을 기준으로 모델을 비교했습니다.

또한 Feature Importance가 높은 피처만 남기거나 상관관계가 높은 피처를 단순히 제거하는 것이 항상 성능 향상으로 이어지는 것은 아니므로, 피처 선택 결과를 실제 교차검증 성능과 함께 확인해야 한다는 점을 배웠습니다. 최종 모델에서도 공구별 예측 성능 차이가 존재했기 때문에, 향후에는 더 다양한 공구와 공정 조건의 데이터에서 일반화 성능을 추가로 검증할 필요가 있습니다.

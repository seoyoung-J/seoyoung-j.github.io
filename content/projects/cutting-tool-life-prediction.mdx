## 프로젝트 개요

CNC 밀링 공정의 진동·전류 센서 통계 피처와 공정 메타데이터를 활용해 절삭공구의 정규화 잔여수명(Remaining Useful Life, RUL)을 예측한 개인 프로젝트입니다. 원본 데이터는 14개 절삭공구의 전체 수명 주기와 968개 밀링 사이클로 구성됐으며, 희소 그룹 제거 후 13개 공구 그룹 967개 샘플을 모델 평가에 사용했습니다.

동일 공구 데이터가 학습과 검증에 함께 포함되지 않도록 TollIndex 기준 GroupKFold를 적용했습니다. 타깃과 입력 변수 조합, 7개 회귀 모델과 피처 구성을 비교해 Top-30 피처 기반 ExtraTreesRegressor를 최종 모델로 선정했습니다.

#### **문제 상황**

공구마다 전체 수명이 달라 실제 잔여 cycle 수인 CycleToFailure의 값 범위도 공구별로 차이가 있었습니다. 공구 단위 GroupKFold 평가에서 **RandomForestRegressor의 R²가 모두 음수로 나타나** 타깃 정의와 누적 사용 정보의 포함 여부를 다시 검토해야 했습니다.

#### **해결 과정**

##### **1. 공구 단위 검증 구조 적용**

- TollIndex 기준 그룹 분포 확인 후 표본 수가 5개 미만인 희소 그룹 제외
- 최종 13개 공구 그룹에 GroupKFold를 적용해 동일 공구 데이터의 학습·검증 중복 방지

##### **2. 타깃과 누적 사용 정보 조합 비교**

- CycleToFailure와 CycleToFailureNormalized를 각각 타깃으로 설정해 공구별 수명 차이에 따른 영향 비교
- 각 타깃에서 NumberOfCycle 포함 여부를 나눈 4개 조합을 동일한 RandomForestRegressor 조건으로 평가

#### **결과**

CycleToFailureNormalized를 타깃으로 사용하고 NumberOfCycle을 포함한 조합에서 **평균 MAE 0.12, RMSE 0.16, R² 0.65**를 기록했습니다. 해당 구성을 이후 회귀 모델 비교와 피처 최적화 실험에 적용했습니다.

#### **문제 상황**

진동 통계 피처 48개와 전류 통계 피처 72개 중 **일부 피처에서 높은 상관관계가 나타났습니다.** 전체 피처를 그대로 사용하는 것보다 예측에 기여하는 피처를 선별하면서 공구별 일반화 성능을 유지하거나 높일 수 있는 구성을 검토했습니다.

#### **해결 과정**

##### **1. Feature Importance 기반 Top-N 비교**

- ExtraTreesRegressor의 Feature Importance를 기준으로 전체 피처와 Top-10, Top-20, Top-30 구성 비교
- 동일한 GroupKFold 조건에서 평균 R²와 오차 지표를 함께 비교해 Top-30 구성 선정

##### **2. 상관관계 기반 추가 피처 축소 검증**

- Top-30 중 상관계수 절댓값이 0.90 이상인 피처는 Feature Importance가 높은 대표 피처만 유지해 16개로 축소
- Top-30과 16개 구성을 동일한 검증 조건에서 비교해 추가 축소에 따른 성능 변화 확인

##### **3. 추가 튜닝 결과 비교**

- Top-30 피처를 고정한 상태에서 GridSearchCV 결과와 기존 Optuna 실험 기록 비교
- 추가 튜닝 결과가 기존 Top-30 설정의 검증 성능을 넘지 못해 현재 설정 유지

#### **결과**

Top-30 피처 적용으로 ExtraTreesRegressor의 평균 R²가 **0.79에서 0.82로 향상**됐습니다. 상관관계 기반으로 16개까지 축소한 구성과 추가 튜닝 결과는 Top-30의 성능을 넘지 못해 Top-30 피처 기반 ExtraTreesRegressor를 최종 모델로 선정했습니다.

| 피처 구성 | R² | MAE | RMSE | 판단 |
| :---: | :---: | :---: | :---: | :---: |
| 전체 피처 | 0.79 | 0.10 | 0.12 | 비교 기준 |
| **Top-30** | **0.82** | **0.09** | **0.12** | **최종 선정** |
| 상관관계 기반 16개 | 0.81 | 0.10 | 0.12 | 미채택 |

## 회고 및 배운 점

정형 데이터 회귀에서는 평균 성능뿐 아니라 데이터가 생성된 단위를 반영한 검증 구조가 중요하다는 점을 배웠습니다. 공구 단위로 학습과 검증을 분리하면서 학습에 포함되지 않은 공구에 대한 일반화 성능과 그룹별 성능 편차를 함께 확인했습니다.

또한 피처 수를 많이 줄이는 것이 항상 최선은 아니며, Feature Importance와 상관관계, 검증 성능을 함께 비교해 최종 피처 구성을 판단해야 한다는 점을 확인했습니다.

## 프로젝트 개요

CNC 밀링 공정의 진동·전류 센서 통계 피처와 공정 메타데이터를 활용해 절삭공구의 정규화 잔여수명 (Remaining Useful Life, RUL)을 예측한 개인 프로젝트입니다. 14개 절삭공구의 전체 수명 주기와 968개 밀링 사이클로 구성된 공개 정형 데이터셋을 사용했습니다.

동일 공구 데이터가 학습과 검증에 함께 포함되지 않도록 `TollIndex` 기준 GroupKFold를 적용했습니다. 타깃과 입력 변수 조합, 7개 회귀 모델, 튜닝 방법과 피처 구성을 비교해 ExtraTreesRegressor와 Top-30 피처를 최종 선정했습니다.

## 주요 성과

### 1. **공구 단위 일반화 검증**

동일 공구 데이터가 학습과 검증에 함께 포함되지 않도록 `TollIndex` 기준 GroupKFold를 적용하고, 학습에 포함되지 않은 공구에 대한 성능을 평가했습니다.

### 2. **회귀 모델 비교 및 최종 모델 선정**

7개 회귀 모델을 동일한 GroupKFold 조건에서 비교하고 상위 3개 모델을 튜닝해 **ExtraTreesRegressor를 최종 모델로 선정했습니다.**

### 3. **피처 최적화를 통한 성능 개선**

전체 피처 기준 **평균 MAE 0.1014, RMSE 0.1228, R² 0.7941**에서 Top-30 피처 적용 후 **MAE 0.0943, RMSE 0.1153, R² 0.8152**로 개선했습니다.

## 트러블슈팅

### **01. 타깃 정규화와 누적 사용 정보 반영으로 RandomForest R² 0.6543 확보**

#### **문제 상황**

공구마다 전체 수명이 달라 실제 잔여 cycle 수인 `CycleToFailure`의 값 범위도 공구별로 차이가 있었습니다. 공구 단위 GroupKFold 평가에서 해당 타깃을 사용한 RandomForestRegressor의 R²가 모두 음수로 나타나 타깃 정의와 누적 사용 정보의 포함 여부를 다시 검토해야 했습니다.

#### **해결 과정**

##### **1. 공구 단위 검증 구조 적용**

- `TollIndex` 기준 그룹 분포를 확인해 표본 수가 5개 미만인 희소 그룹 제외
- 최종 13개 공구 그룹을 기준으로 GroupKFold 학습·검증 구조 적용
- 동일 공구 데이터가 학습과 검증에 함께 포함되지 않도록 분할

##### **2. 타깃과 입력 변수 조합 비교**

- 타깃 조합 비교를 위한 기준 모델로 RandomForestRegressor 사용
- `CycleToFailure`와 `CycleToFailureNormalized` 타깃 비교
- 각 타깃에서 `NumberOfCycle` 포함 여부에 따른 4개 조합 평가

#### **결과**

`CycleToFailureNormalized`를 타깃으로 사용하고 `NumberOfCycle`을 입력 변수에 포함한 조합에서 **평균 MAE 0.1249, RMSE 0.1557, R² 0.6543**을 기록했습니다. 이는 타깃과 입력 변수 조합을 선정하기 위한 중간 실험 결과이며, 해당 조합을 이후 7개 회귀 모델 비교와 튜닝에 동일하게 적용했습니다.

### **02. Top-30 피처 선정으로 ExtraTrees 평균 R² 0.7941 → 0.8152 향상**

#### **문제 상황**

입력 데이터에는 진동 통계 피처 48개와 전류 통계 피처 72개가 포함돼 있었으며, 일부 피처 사이에는 높은 상관관계가 존재했습니다. 중복된 정보를 줄이면서도 잔여수명 예측에 필요한 정보를 유지할 수 있는 피처 구성을 선정해야 했습니다.

#### **해결 과정**

##### **1. 피처 중요도 기반 Top-N 비교**

- ExtraTreesRegressor의 피처 중요도를 기준으로 Top-10, Top-20, Top-30 피처 구성 생성
- 전체 피처를 포함한 각 구성을 동일한 GroupKFold 조건에서 비교
- 평균 R²가 가장 높은 Top-30 구성을 최종 피처 후보로 선정

##### **2. 상관관계 기반 피처 축소 검증**

- Top-30 피처 중 상관계수 절댓값이 0.9 이상인 피처 그룹 확인
- 각 그룹에서 중요도가 가장 높은 대표 피처만 유지한 16개 피처 구성 생성
- Top-30 전체 구성과 16개 축소 구성의 MAE, RMSE, R² 비교

#### **추가 실험 및 판단**

- 16개 피처 구성은 R² 0.8112로 Top-30 구성의 0.8152보다 낮아 최종 미채택

#### **결과**

전체 피처를 사용한 ExtraTreesRegressor의 평균 성능은 **MAE 0.1014, RMSE 0.1228, R² 0.7941**이었습니다. Top-30 피처 적용 후 **MAE 0.0943, RMSE 0.1153, R² 0.8152**를 기록해 모든 평가 지표가 개선됐으며, 16개 축소 구성보다 성능이 높은 **Top-30 전체 구성**을 최종 선택했습니다.

## 한계 및 개선 방향

- 데이터가 14개 공구와 968개 밀링 사이클로 제한돼 다양한 공구 유형과 가공 조건을 포괄하는 데 한계가 있습니다.
- fold별 R² 편차가 나타나 공구 그룹에 따라 일반화 난이도가 달라질 수 있습니다.
- `NumberOfCycle`의 중요도가 높아 센서 피처만의 독립적인 설명력을 해석할 때 주의가 필요합니다.
- 센서 원신호가 아닌 추출된 통계 피처를 사용해 시간에 따른 신호 변화를 직접 학습하지 못했습니다.

## 회고 및 배운 점

정형 데이터 회귀에서는 모델의 평균 성능뿐 아니라 데이터가 생성된 단위를 반영한 검증 구조가 중요하다는 점을 배웠습니다. 공구 단위로 학습과 검증을 분리하면서 학습에 포함되지 않은 공구에 대한 일반화 성능과 공구별 성능 편차를 함께 확인했습니다.

또한 피처 수를 많이 줄이는 것이 항상 최선은 아니며, 피처 중요도와 상관관계, 검증 성능을 함께 비교해 성능과 해석성 사이의 균형을 판단해야 한다는 점을 확인했습니다.
